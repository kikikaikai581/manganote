# まんがノート（スマホ内保存・オフライン対応）

## ファイル
- `index.html`: アプリ本体
- `manifest.webmanifest`: ホーム画面追加用設定
- `sw.js`: オフラインキャッシュ
- `icon.svg`: アイコン

## Androidスマホだけで公開する簡単な方法（GitHub Pages）
1. ブラウザで GitHub にサインイン（アカウントがなければ作成）。
2. `+` → `New repository` で `manga-note` などの名前を付け、Public を選んで作成。
3. リポジトリ画面で `Add file` → `Upload files` を選ぶ。
4. このZIPを端末で解凍し、中の4ファイルをアップロード。ZIP自体ではなく、ファイルをアップロードする。
5. `Commit changes` を押す。
6. リポジトリの `Settings` → `Pages` を開く。
7. `Build and deployment` の Source を `Deploy from a branch`、Branch を `main`、フォルダを `/(root)` にして Save。
8. 数分後に表示される `https://ユーザー名.github.io/manga-note/` のURLをChromeで開く。
9. Chromeの︙メニュー → `ホーム画面に追加`（または `アプリをインストール`）を選ぶ。
10. アプリをオンラインで一度開き、作品を登録。オフライン動作を試すときは、最初のキャッシュ完了後に機内モードで開く。

## 注意
- 初回アクセス・アプリの更新にはインターネットが必要。
- データはそのブラウザ/サイト内のIndexedDBに保存され、同じURLを同じブラウザで開く限り保持される。
- ブラウザのデータ消去、アプリ/サイトデータの削除、端末故障、ブラウザ変更で失われる場合があるため、定期的にアプリ内のバックアップを保存する。
- このアプリはクラウド同期をしない。公開URLを知っている人はアプリ自体を開けるが、各人の登録データはそれぞれの端末・ブラウザ内に保存される。個人情報や機微情報は記録しない。
- 表紙画像は縮小して端末内に保存される。JSONバックアップにも画像が含まれるため、作品数が多いとファイルが大きくなることがある。
- GitHub Pagesの画面は更新される場合がある。メニュー名が多少違うときは、Pages設定で `main` と `/(root)` を公開元に選ぶ。
